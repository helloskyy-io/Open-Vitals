Notes
- Phase 0 runs without Django; CLI + notebooks generate figures for the class.
- Phase 1 adds services/backend (Django API + frontend) and services/temporal-workers; both read Postgres and trigger Temporal.
- The orchestration/temporal package keeps Temporal code isolated from core parsing/analytics logic.
- data/ is always local-only (raw exports must never be committed).
