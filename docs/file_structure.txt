Notes
- Phase 0 runs without Django; Temporal (bootstrap + Genesis) deploys OpenVitals Postgres; worker runs workflows/activities.
- data/ is always local-only (raw exports must never be committed).
- Bronze/Silver/Gold: raw/ = landing zone (exports arrive); bronze/ = deduplicated raw store + manifest; Silver = Postgres canonical tables (schema_v0); Gold = derived metrics + data/processed outputs.
- Python packages use __init__.py (not shown above). Worker image built from repo root requirements.txt.
